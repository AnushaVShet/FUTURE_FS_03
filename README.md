# ANVÉRA — Fashion E-Commerce Store

**Tradition, Reimagined.**

ANVÉRA is a premium Indian fashion e-commerce website designed for a contemporary local fashion boutique. The platform allows customers to explore products, view product details, add items to their bag, place orders, and track their orders.

The project also includes an admin panel for managing products, customers, stock, and orders.

---

## ✨ Features

### Customer Features
- Premium fashion-focused homepage
- Browse all products
- Category-based product filtering
- Product search and sorting
- Product details with sizes, price and stock
- Add products to bag
- Update quantities and remove products
- Checkout and customer details
- Order placement
- Order confirmation
- My Orders page
- Order status tracking

### Admin Features
- Secure admin login
- Admin dashboard
- Product management
- Add, edit and delete products
- Update product stock
- Customer management
- Order management
- Update order status
- Protected admin APIs

💡 Business Purpose

ANVÉRA is designed to help a local fashion boutique establish an online presence and provide customers with a convenient way to discover and purchase Indian fashion products.

The website provides a digital storefront while the admin panel helps the business manage products, inventory, customers and orders.
